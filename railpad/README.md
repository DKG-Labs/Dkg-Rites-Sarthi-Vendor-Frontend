# SARTHI - Rail Pad Vendor Portal

Automated Real-time Tracking & Health Inspection (SARTHI) for Rail Pad Vendors.

## Modules
- **Vendor Dashboard**: Real-time stats, trends, and recent POs.
- **PO Management**: View and update purchase orders.
- **Inspection Calls**: Raise and track inspection calls.

## Tech Stack
- React 19
- Vite 7
- Vanilla CSS

## Development
```bash
npm install
npm run dev
```
